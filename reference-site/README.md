# 站内页面快照

**双击 `index.html` 就能看**，不用装 Node、不用起服务、不用连数据库。

| 文件 | 是什么 |
|---|---|
| `index.html` | 入口页，四个页面的索引 |
| `home.html` | 首页（深色星图） |
| `tools.html` | 工具列表页 |
| `tool-cursor.html` | 工具详情页，Cursor |
| `guides.html` | 现有的「编辑首选」文章列表 |

## 这是什么

2026-10-17 从本地跑起来的真实站点导出的静态快照。CSS、字体、图片都内联在文件里，所以断网也能打开。

导出时把页面从头滚到底、等所有入场动画跑完，再把动画定格在终态。所以你打开就能看到每一屏完整的样子，不用等动画、不用滚动触发。

## 为什么没有脚本

Next.js 的交互要靠服务端接口和一堆 JS chunk，离线打开必然失败，页面会白屏。所以快照里把脚本去掉了，保留的是**渲染完成后的 DOM**：画面和线上一致，但点不动。

具体表现：

- 搜索框、筛选药丸、皮肤切换这些点了没反应；
- 链接只在四个快照之间跳转（首页、工具列表、工具详情、文章列表），其他链接不可点；
- 页面是「导出那一刻」的样子，不会随数据更新。

**要交互、要改代码，去根目录的 Next.js 项目**：`pnpm install && pnpm dev`。

## 不要做的事

1. **不要改这几个 HTML。** 它们是导出物，不是源码。
2. **不要照着里面的 HTML 写代码。** 那是框架打包后的产物，class 名是一串 hash，读不出结构。
3. **不要把里面的数字当真。** 快照用的是本地种子数据（16 个工具、10 个模型），仓库 `data/products/` 里是另外 22 个。

## 怎么重新导出

站点跑在 3001 端口时：

```bash
python scripts/snapshot-site.py
```

脚本在仓库根目录的 `scripts/` 下，前面的注释写了它在做什么。
