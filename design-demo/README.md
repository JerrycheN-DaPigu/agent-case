# 完整设计 demo

**双击 `index.html`**，用 Chrome 或 Edge 打开。不用装 Node、不用起服务、不用连数据库，断网也能用。

这是站内前端的**设计与交互演示**，不是线上站点：能点的都做出来了，数据是 2026-10-06 整理的演示数据，没有后台。

## 能点什么

| 位置 | 能做什么 |
|---|---|
| 首页四张玻璃卡 | 模型 / 工具 / 比赛 / 共创，鼠标在首屏移动有视差 |
| 模型 | 右上角切「能力榜 / 性价比榜」；点厂商看它全部模型；点柱子或名字进详情 |
| 工具 | 顶部按钮筛选（当前福利 / 新手首选 / 国内可用 / 开源 / 编程 / 办公 Agent / AIGC）；点进套餐详情 |
| 比赛 | 赛道、地区、奖金筛选；右上角切「截止日历」；点比赛看赛程 |
| 搜索 | 右上角放大镜，或 `Ctrl+K` |
| 主题 | 左下角「◐ 主题」，切夜墨 / 石墨白 / 冷灰蓝，还能换强调色 |

工具页里 **opencode、Claude Code、Codex、Cursor、TRAE、WorkBuddy** 有完整的套餐详情，做工具指南页时重点看这几家的详情页结构。

## 和线上站点什么关系

- 版式、颜色、字号、交互：**一致**。这就是定稿 demo，线上页面是按它实现的。
- 内容：demo 是 2026-10-06 的快照（17 个工具、63 个模型），线上是实时数据，仓库 `data/products/` 里又是另外 22 个。**看版式，不看数字。**
- 顶栏现在线上是「共创 / 模型 / 工具 / 比赛」，和这里一样。

## 做过什么改动

原 demo 是给内部看的，有两处外网依赖，我换成了本地的：

1. **Google Fonts → 本地字体**（`fonts/`）。国内打不开 Google Fonts，原来会掉成宋体/系统字体。
2. **three.js CDN → 本地**（`vendor/three/`）。3D 地图那条链路原来要连 jsDelivr。

现在整个文件夹自包含，断网打开也没有任何外部请求。

## 不要做的事

1. **不要改这些文件。** 这是演示稿，不是你要改的工程。要写页面去根目录的 Next.js 项目。
2. **不要把这里的 HTML/CSS 抄进项目。** 它是单文件演示，写法和 Next.js 工程不一样（比如全站样式塞在一个 `<style>` 里，没有模块化）。
3. **不要拿里面的数据当真。** 上面说过，看版式。
