## 该学的

1. **三栏**：左边工具目录、中间正文、右边「本页目录」。右边这一栏浅色、字号小，只做导航不抢注意力。
2. **左目录按类分组、可折叠**，当前项浅色底 + 左侧竖线高亮。
3. **正文的节奏**：大标题 → 一句话说明 → 重点提示块 → 小节标题 → 小节内容。每屏都有明确的信息块，不堆长段落。
4. **卡片做入口**：总览页用 2 列卡片概括「你可以怎么用」，每张卡有图标、短标题、一两句说明。
5. **详情页顶部**：分类标签、标题、摘要、更新时间，然后才进正文。
6. **手机端**：左目录收进顶部一个下拉（显示当前小节），正文单列铺满。

## 别学的

1. **配色**：它是浅色文档站。我们要的是起源AI 的「夜墨」深色皮肤——颜色全部走 `src/styles/tokens.css`。
2. **文案**：不要抄它的句子、标题和「On this page」这类英文标签（我们用「本页目录」）。
3. **Copy Markdown 按钮、搜索框**：不是这个 case 的要求，做了不加分。
4. **它的信息密度**：它是产品说明书式的写法。我们的教程要更「手把手」，每一步要写到「点哪里、输入什么、看到什么」。
