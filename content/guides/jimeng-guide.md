## 它能做什么

即梦AI 是字节剪映团队的 AI 图像视频工具，网页版打开就能用：输入一段中文描述生成图片，也可以上传一张图让它动起来，生成几秒的视频。

适合：做封面图、社媒配图、短视频空镜；需要中文提示词直接出图的人；不想装本地大模型的人。

不适合：要求像素级可控的商业设计（它的随机性仍然很大）；需要长视频、多镜头叙事的项目（单次生成时长有限）。

## 国内怎么用

网页版地址是 https://jimeng.jianying.com/ ，国内网络可直接访问，手机号或抖音账号登录。`data/products/jimeng.yaml` 里 `accessCN` 是 `true`。

不用境外手机号，也不用境外支付。每天登录会送一定积分，生成图片和视频都扣积分，具体额度以页面显示为准。

## 安装

网页版不需要安装，用 Chrome 或 Edge 打开官网即可。也有手机 App，在应用商店搜「即梦」下载，功能和网页版不完全一样。

如果要用它的「智能画布」「局部重绘」这类桌面级功能，网页版同样能用，不用另外装软件。

## 登录与开通

1. 打开 https://jimeng.jianying.com/ ，右上角点「登录」。
2. 选手机号验证码登录，或用抖音扫码。
3. 登录后回到首页，左上角能看到「图片生成」「视频生成」两个入口。
4. 页面角落会显示剩余积分；会员页里能看套餐和每日赠送规则。

## 跑通第一个任务

目标：生成一张图，再把它变成一段视频。

1. 在首页点「图片生成」。
2. 在提示词框里输入：一只橘猫坐在窗台上，午后阳光，浅景深，写实风格。
3. 选比例（先用 1:1 或 3:4），模型选默认的那个，点「生成」。
4. 等 10–30 秒，会出 4 张候选图；点其中一张放大，再点「下载」存到本地。
5. 回到该图的详情，点「生成视频」，提示词写：镜头缓慢推近，猫眨眼。时长选 3 秒或 5 秒（看你账号可用档位），点生成。
6. 生成完预览，满意就下载 MP4。

第一次就出废图很正常：换描述词里的风格和光线，比反复点重新生成更有效。

## 接入自己的模型 / API Key

网页版不开放填自己的 API Key，模型和额度都走官方。要给团队批量调用，看火山引擎的即梦相关接口，那是另一套账号和计费，和这个网页版不是同一个入口。

## 怎么付费

先用每天赠送的积分。要连续出图再买会员，价格和赠送额度见站内会员页；本站不写死数字。

## 常见问题

**点了生成没反应。** 现象是按钮变灰后一直转圈。原因是队列排队或积分不足。怎么办：先看右上角积分；积分够就等 1 分钟再刷新页面重试。
**生成的图和描述差很远。** 现象是主体对了但风格不对。原因是提示词里风格词太笼统。怎么办：把「好看」换成具体词，例如「胶片颗粒、暖色逆光、35mm」。
**视频只有几秒，且动作很怪。** 现象是人物手脚变形。原因是单次生成时长越长越容易崩。怎么办：先用 3 秒、动作写简单一点（转头、微笑），稳定后再加长。
**下载的图有水印。** 现象是右下角带平台标识。原因是免费档导出带水印。怎么办：会员档可去水印，或者用「高清放大」后再裁掉边角。
