## 它能做什么

TRAE 是字节做的 AI 编辑器，界面和用法接近 VS Code，分国内版和海外版。国内版用手机号注册，内置国内模型，不用自己配 API Key 也能对话和生成代码。

适合：想试 AI 编程但不想折腾账号和支付的人；已经会用 VS Code、想加一个「对话改代码」入口的人；要快速搭一个能跑的前端页面。

不适合：需要重度自定义插件和调试配置的人——插件生态还在长；以及对代码上传有硬性合规要求的团队。

它和海外版最大的区别是模型池：国内版默认给豆包、DeepSeek 这类国内模型，响应快、不用代理；海外版给 Claude、GPT，效果上限高一些，但要解决网络。选择哪一个，先看你更缺「稳定」还是更缺「效果」。

## 国内怎么用

国内版官网是 https://www.trae.cn/ ，手机号注册，国内网络可直接访问。`data/products/trae.yaml` 里 `accessCN` 是 `true`。

海外版是 https://www.trae.ai/ ，账号体系和模型不同，国内访问稳定性看网络。两边数据不互通，别在一边登录后去另一边找项目。

国内版还有个实际好处：它的模型调用走国内机房，白天高峰期也不容易超时；代价是模型版本更新比海外慢半拍。如果你照着海外教程操作，会发现同一个功能的名字和位置对不上，这不是你装错了。

## 安装

1. 打开 https://www.trae.cn/ ，点页面上的「下载」。
2. 选择系统：Windows 给的是 .exe 安装包，macOS 给的是 .dmg。
3. Windows 双击安装，中途会问安装路径，默认即可；装完桌面有图标。
4. macOS 打开 .dmg，把 TRAE 拖进「应用程序」。第一次打开如果提示「无法验证开发者」，去「系统设置 → 隐私与安全性」点「仍要打开」。

没有命令行安装方式，也不需要先装 Node。

安装包大约几百 MB，装完占用 1 GB 上下，主要空间在模型缓存。装在系统盘还是其他盘都行，但项目目录建议放纯英文路径，后面跑终端命令会少一类麻烦。

## 登录与开通

1. 打开 TRAE，首次启动会停在登录页。
2. 选「手机号登录」，输入大陆手机号，收验证码。
3. 勾选协议后进入主界面。
4. 免费额度够把本文的流程走完；Pro 的价格和额度见官网价格页，别照着旧文章里的数字。

登录后右上角头像里能看到当前套餐和剩余额度。

免费额度和付费额度是分开计的：每月赠送的部分用不完不累计，付费部分按自然月重置。团队协作、多设备同时登录都会消耗额度，先自己用一个账号跑通再拉人。

## 跑通第一个任务

目标：用 Builder 生成一个能打开的页面，再手动改一行。

1. 打开 TRAE，点左上角「文件 → 新建项目」，选一个空文件夹，例如 trae-demo。
2. 在主界面找到对话入口（国内版叫 Builder 或「对话」，不同版本文案会变），切到能生成项目的模式。
3. 在输入框里写：做一个单页 HTML，标题是「我的第一个页面」，下面有一个输入框和一个按钮，点按钮把输入框内容显示在页面上。回车。
4. 等它把文件写出来，左侧文件树里会出现 index.html。
5. 打开 index.html，找到 h1 标签，把文字改成你的名字，按 Ctrl + S 保存。
6. 右键 index.html 选「在浏览器中打开」，输入几个字点按钮，看结果有没有出现。

如果第 3 步生成的是 React 项目而不是单文件，不用重来：按它给的说明装依赖、跑起来，效果一样算跑通。

生成的页面是静态文件，不需要装依赖也能双击打开；这一步的意义是确认「模型 → 文件 → 浏览器」这条链路是通的，后面再让它做需要构建的项目。

## 接入自己的模型 / API Key

国内版默认用内置模型，一般不需要填 Key。需要接自己的模型时，在设置里找「模型」或「模型服务」一栏，按厂商文档填 Base URL、API Key 和模型名。海外版支持在设置里切换 Claude、GPT 等模型。

能不能填、填几个字段，各版本差异很大，以你本机设置页为准；找不到入口时直接问对话里的助手「怎么配置自定义模型」，它给出的路径通常和当前版本一致。

## 怎么付费

先用免费额度。确认每天都会用，再看 Pro 的额度和价格是否划算，入口在官网价格页和客户端右上角。本站不写死价格。

## 常见问题

**手机号收不到验证码。** 现象是倒计时结束也没短信。原因可能是号段被限流，或前面已经发过多次。怎么办：等 5 分钟再试，或换一个手机号；同一网络下频繁注册也会触发风控。

**Builder 生成到一半停了。** 现象是文件只写了一半，或者提示额度不足。原因是用量到顶或网络断了。怎么办：先看头像里的额度；额度够就重试一次，让它「继续完成」。

**打开项目提示找不到 Node。** 现象是终端里报 node: command not found。原因是项目需要本地跑构建，但机器没装 Node。怎么办：装 Node 20 以上，重开 TRAE，再在终端里敲 node -v 确认。

**中文路径下项目打不开。** 现象是选了带中文的文件夹后一直空白。原因是部分工具链对非 ASCII 路径支持不好。怎么办：把项目放到 D:\projects\trae-demo 这种纯英文路径下重开。

**登录后界面是英文。** 现象是菜单、按钮全是英文。原因是安装包按系统语言选了界面语言。怎么办：在设置里找 Language，切成简体中文，重启客户端生效。
