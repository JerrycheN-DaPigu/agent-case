## 三条要先记住

1. **内页是浅色（石墨白皮肤），不是深色。** 只有首页首屏是深色星图。工具、套餐、文章这些内页都是暖白纸底 `#f5f5f3`，`<html>` 上的 `data-skin="paper"` 就是这个。
2. **没有圆角、没有阴影。** 全站靠 1px 的线分隔（`--line`），卡片也是方角。`tokens.css` 里 `--r-*` 全是 0 就是这个意思。
3. **强调色（朱红）只出现在几处**：站标印章、主按钮、7 天内截止的徽标。其他地方一律用墨色和灰。

## 具体到你的页面

- 顶栏直接用仓库里的（已经和站内一致），不要重做。
- 页头的写法照 `工具列表-桌面.jpg`：一行小字（编号 + 数量 + 数据日期）→ 一个很大的中文标题 → 一句说明。
- 左侧目录照价格的粗细关系：分组标题大一号，条目小一号，当前项加底色或竖线。
- 右侧「本页目录」站内没有现成例子，照 priceai 那种浅灰小字即可，但颜色要用 `--mute`，不要用它的绿色。

## 怎么打开

直接双击 `.jpg` 用图片查看器看就行，不需要装任何东西。想在浏览器里看真实页面，必须连站内的数据库，这个 case 里没有提供——所以用截图。
