# 图标来源（脚本生成，勿手改）

本目录的文件由 `apps/web/scripts/fetch-icons.mts` 下载，清单在
`apps/web/src/content/brand-icons.ts`。要换图标：改那张表，再跑
`pnpm --filter web icons:fetch`。

图标（或其产品标识）的版权与商标权归各权利人所有，本站只用于指称与识别；
详见关于页的说明。
