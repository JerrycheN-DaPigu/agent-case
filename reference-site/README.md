# 站内页面快照

**双击 `index.html` 就能看**，不用装 Node、不用起服务、不用连数据库。

| 文件 | 是什么 |
|---|---|
| `index.html` | 入口页，三个页面的索引 |
| `tools.html` | 工具列表页（真实页面） |
| `tool-cursor.html` | 工具详情页，Cursor（真实页面） |
| `guides.html` | 现有的「编辑首选」文章列表（真实页面） |

## 这是什么

2026-10-17 从本地跑起来的真实站点导出的静态快照。CSS、字体、图片都内联在文件里，所以断网也能打开。

**去掉了脚本**，所以：

- 搜索、筛选、下拉、悬停展开这些交互点不动；
- 链接只在快照之间跳转，其他链接不可点；
- 页面是「打开那一刻」的样子，不会随数据更新。

它只解决一件事：**让你知道站内页面长什么样、版式怎么排**。

## 不要做的事

1. **不要改这几个文件。** 它们是导出物，不是源码。
2. **不要照着里面的 HTML 写代码。** 那是框架打包后的产物，class 名是一串 hash，读不出结构。
3. **不要把里面的数字当真。** 快照用的是本地种子数据（16 个工具、10 个模型），仓库 `data/products/` 里是另外 22 个。

## 要写页面去哪儿

根目录的 Next.js 项目：

```bash
pnpm install
pnpm dev     # http://localhost:3000/guides
```

那个项目里已经有和站内一致的顶栏、页脚、设计令牌，你只需要把 `/guides` 和 `/guides/[slug]` 做出来。
